사격장 확인창 글자 가림과 빠진 마침표를 고친 판입니다.

**원본 일본판 이미지에 적용하는 전체 패치입니다.** v0.5 이하를 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

- 사격장 시작 확인창에서 첫 줄이 「예/아니요」 칸에 가려지던 문제를 고쳤습니다.
- 재난 파일 본문, 스테이지 줄거리, 시스템 메시지, 무기 설명, 해금 안내에서 빠졌던 마침표를 되살렸습니다.
- 대사 몇 줄의 번역을 다듬었습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `RDZJ_KPatch_v0.5.1.zip` | 원본 일본판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 지원 형식

| 원본 | 결과 |
|---|---|
| ISO (정본 덤프, WBFS에서 변환한 ISO 등) | ISO |
| WBFS | WBFS |
| CISO, WIA, WDF | ISO |
| RVZ · NKit | 지원 안 함. ISO로 변환·복원한 뒤 적용 |

덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.

## 적용 방법

1. zip을 풀고 원본 이미지(ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다. 원본을 같은 폴더에 넣고 더블클릭해도 됩니다.
2. `완료`가 나올 때까지 기다립니다(1분에서 2분 정도).
3. 원본과 같은 폴더에 결과 파일이 생깁니다.
   - ISO 원본 → `Disaster (Korean) [RDZJ01].iso`
   - WBFS 원본 → `Disaster (Korean) [RDZJ01].wbfs`

결과 형식을 바꾸려면 패처 폴더의 PowerShell에서 `powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"`처럼 결과 확장자를 지정합니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 오류 메시지와 해결 방법은 동봉한 `README_한국어.txt`를 참고하세요.
